A single warning label for a time machine, written to get a laugh — deadpan safety notice, real paradox inside.

Entry for the make.fun bounty: https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151

## Run

```sh
python3 main.py
```

It writes the label to `/output/entry.txt` (UTF-8, 105 characters, one line).

## The label

> WARNING: Do not speak to yourself. He already knows what you were going to say, and he already disagrees.
